## About

Computer Science graduate from the **University of North Texas** building AI/ML systems that connect research-grade models with production software. My work spans **LLM applications, retrieval and ranking, recommendation systems, computer vision, backend APIs, and evaluation infrastructure**.

I am especially interested in systems where model quality and software engineering have to work together: reliable retrieval, grounded generation, measurable evaluation, scalable APIs, and intelligent user-facing products.

Research on adapting from synthetic leaf imagery to previously unseen real weed classes using texture-prior pretraining and Model-Agnostic Meta-Learning.
